# 示例资料来源与改动

`samples/course/` 中的笔记均为本项目为了验收而编写的原创摘要，不是官方资料的复制版本。

- `01-seekdb混合检索.md`：依据 <https://github.com/oceanbase/seekdb> 和 <https://github.com/oceanbase/pyseekdb> 的公开 README 整理，增加了复习解释与质量检查要点。
- `02-PowerContext记忆.md`：依据 <https://github.com/oceanbase/powercontext> 及其 Atomic Memory 公开文档整理，增加了本应用的分工说明。
- `03-本地文本向量.txt`：依据 <https://huggingface.co/BAAI/bge-small-zh-v1.5> 公开模型卡整理，增加了本地导入时的使用注意事项。
- `04-检索评估速查.pdf`：依据上述 seekdb、pyseekdb 与 PowerContext 公开文档编写的双页原创验收资料，用于验证 PDF 文本提取、按页切块和页码展示。

官方名称、接口名与链接归原项目所有；示例摘要仅用于本赛题的功能验证。
