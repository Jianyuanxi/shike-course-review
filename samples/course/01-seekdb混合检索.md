# seekdb 混合检索

混合检索把关键词匹配与向量语义匹配结合起来。关键词检索适合查找明确的术语、函数名和文件名，向量检索则能发现措辞不同但含义相近的段落。两路结果通过 RRF（Reciprocal Rank Fusion，倒数排名融合）合并，避免只依赖单一信号。

在 pyseekdb 中，Collection 的 document 字段保存原文，embedding 字段保存向量，metadata 保存出处等结构化信息。hybrid_search 的 query 部分负责全文检索，knn 部分负责向量检索，rank 部分可以配置 RRF。

复习时要区分“全文条件过滤后做向量排序”和“两路独立召回后融合”。后者允许一个段落即使没有命中完整关键词，也能依靠语义相似度进入候选集。

# 向量索引与全文索引

HNSW 是常用的近似最近邻向量索引。余弦距离关注向量方向，适合配合归一化文本向量。中文全文检索需要合适的分词器，pyseekdb 创建 Collection 时使用 IK 分词。

出处元数据不参与向量计算，但可以用于用户隔离、按文档过滤以及找回上下文。常见元数据包括文件名、页码、段落号和块序号。

# 检索质量检查

评估检索结果时，不仅要看是否返回五条内容，还要检查出处是否准确、上下文是否完整，以及同义问题能否召回同一知识点。检索日志应保存原始问题、候选排名和最终排名，便于复盘。
